# 环境与部署
> 凭据处理、容器更新和远端状态核验的约定。

公开默认配置在 `magpie-config/`，实际凭据使用仓库外的配置和 env-file，成员使用的密钥优先放进 OpenBao。修改 env-file 后需要重建容器；重启只能读取文件挂载的新内容，不能更新 Docker 创建时的环境变量。

更新部署前核对当前镜像、Compose、工作目录、数据卷和活动任务。保持 home、Docker 数据和项目目录，保留可回退的镜像与配置。与当前任务无关的团队和仓库不作清理。

远端项目路径与服务地址先从已有部署事实召回，再现场核实。使用已配置的 ah 连接及私有认证，不把密钥写进命令或文档。宿主机使用 `docker-compose` 还是 `docker compose` 应现场检查。

检查 Magpie 日志时先过滤带 Key 的登录链接。检查 Agent 时结合注册信息、实际进程或 tmux 会话；面板存在团队成员不等于运行进程在线。

推送远端遵循当前用户授权和自动审批结果。自动审批拒绝时保留本地提交，完成未受影响的工作，说明拒绝的操作与原因；不通过其他入口绕过。
