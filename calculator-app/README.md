# 计算器 Web App

零依赖、无构建的响应式计算器（表达式模式）。实现依据
[`docs/requirements.md`](./docs/requirements.md) 与
[`docs/architecture.md`](./docs/architecture.md)。

## 运行

```bash
# 单元测试（Node 22 内置测试运行器，无需 npm install）
node --test

# 本地静态服务器（可选，仅开发用）
node scripts/dev-server.mjs        # http://localhost:8080
```

浏览器直接访问静态服务器地址即可。`localStorage` 在 `file://` 下行为不可靠，
请通过 HTTP(S) 访问。部署时把 `index.html` + `src/` 原样放到任意静态目录（相对路径，
支持子路径）；无需构建步骤，也无运行时 npm 依赖。

## 目录

```
index.html              # 语义结构 + CSP meta
src/
  main.js               # 组装 store / 视图 / 键盘 / 存储
  app/                  # actions、纯 reducer、store（持久化副作用）
  core/                 # tokenizer、parser、evaluator、formatter、serializer、limits、errors
  storage/              # localStorage 适配器（注入式，便于测试）
  ui/                   # 计算器视图、历史视图、键盘映射、DOM 辅助
  styles/main.css       # 响应式 / 深色模式 / 可访问性样式
scripts/dev-server.mjs  # node:http 静态服务器
test/                   # node:test 单元测试与安全静态检查
```

依赖方向：`core ← app ← ui`，`core ← app → storage`；`core/` 不引用 DOM / 存储。
禁止 `eval` / `new Function` / 字符串定时器 / 通过 `innerHTML` 写入用户数据，
由 `test/no-eval.test.js` 静态扫描兜底。

## 语义要点

- **表达式模式**：按键只编辑表达式，按 `=` 才提交结果并写历史；编辑中显示弱化预览。
- **百分号**：`x%` 统一等于 `x / 100`，可叠加（`50 + 10%` = `50.1`，`50%%` = `0.005`）。
  这是 leader 已确认的语义（OQ-1 默认），不是上下文百分号。
- **一元负号**：按位置区分；`−3%` = `−(3%)` = `-0.03`；`2 − −3` = `5`；`−−3` = `3`。
- **优先级**：括号 > 后缀 `%` > 一元 `+/-` > `× ÷` > `+ −`（左结合）。
- **显示**：15 位有效数字稳定化（`0.1 + 0.2` 显示 `0.3`），`|x| >= 1e16` 或
  `0 < |x| < 1e-6` 用科学计数法，负零显示 `0`。内部为 IEEE-754 双精度，
  **不适用于金融级/法定计量精度**。
- **历史**：仅在求值成功时追加，最新在前，上限 50，相同表达式+结果只刷新时间；
  键名 `calculator.history.v1`，版本化；`localStorage` 不可用时降级为会话内历史并提示。
- **错误**：除零、溢出、括号不匹配、隐式乘法、超长/超深等返回结构化错误码与中文文案；
  错误不清空输入，数字 / AC / DEL 可恢复。

## 上限

| 项 | 上限 |
| --- | --- |
| 单个数字有效位 | 15 |
| 单个数字字符数 | 32 |
| 表达式长度（序列化） | 128 |
| 括号嵌套 | 16 |
| 历史条数 | 50 |

超限输入在 UI 层被忽略并显示轻提示，不进入错误态；历史/回填数据在核心层重新校验。

## 实现说明（与设计文档的差异记录）

- `CalcState` 增加只读展示字段 `notice`（`string | null`），用于承载「超限输入」的
  一次性轻提示。设计文档 §7.3 要求该提示，但 §8.1 的状态形状未列此字段；
  它不参与计算语义、不持久化，属于 UI 展示扩展。
- 退格对数字按字符删除（如 `123` → `12`），对运算符/括号/百分号按 token 删除；
  结果回填的科学计数数字按 token 删除，避免产生非法数字字面量。
- 历史面板在桌面常驻、窄屏可开合；`h` 键与面板按钮均可开合，面板打开时 `Escape`
  优先关闭面板。

## 验收与测试

- 单测覆盖：优先级、括号与嵌套上限、一元负号、百分号（含 `50+10%=50.1`）、
  除零、溢出/下溢、`0.1+0.2`、格式化、序列化 round-trip、状态机（输入规则、
  清除/退格、求值后继续、错误恢复、`±`）、历史去重/上限/载入/清空、存储降级、
  静态安全扫描。
- 浏览器人工验收清单仍按需求文档 §9（AC-1 ~ AC-14）执行；本期不引入 Playwright/jsdom。

## 限制

- 二进制浮点精度（约 15–17 位有效数字），展示层固定 15 位；不支持任意精度。
- 不做隐式乘法、科学函数、记忆键、上下文百分号、重复按 `=`、复制结果（P2）。
- 无 Service Worker，不支持离线首次加载；页面加载后不发起任何网络请求。
- 深色模式跟随系统（P1）；无手动主题切换。
